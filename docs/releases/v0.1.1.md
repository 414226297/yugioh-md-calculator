# 联栗炮助手 v0.1.1

首个 GitHub 试用版本，面向 Windows x64 的《游戏王 Master Duel》联栗炮计算侧栏。

## 当前功能

- 从牌组编辑界面获取自己的主牌组和额外牌组，并用于紧接着的一场对局。
- 显示双方手牌、场上数量及合计，按种类展示对方表侧怪兽等级和阶级。
- 根据两段数值条件、额外牌组及已确认的表侧除外材料计算方案。
- 跟踪已识别的材料移动，汇总除外区融合等级和超量阶级。
- 支持手动核对数量、怪兽数值和库存，以及暂停、重连和恢复自动读取；未知或过期数据会阻止确定推荐。

## 本版修复

修复全新配置首次下载卡片属性失败，导致牌组已经读到却无法显示获取成功的问题。

## 下载与使用

下载下方 Windows x64 ZIP 并完整解压，运行 `MD-Cannon-Assistant.exe`；无需安装 Node.js、pnpm 或 Codex。附带 SHA256 文件可校验下载完整性。

自动读取仍需本机安装 MD 和兼容的 Untapped Companion 原生读取模块，便携包不包含该模块。首次获取卡片属性需要联网。在 MD 打开牌组编辑界面，等到获取成功后进入对局。

## 验证与限制

- 构建、46 项单元测试和 10 组界面检查通过，0 失败、0 跳过；实际 ZIP 在中文及空格目录、空白配置下启动验收通过。
- 此前本机实测已验证 40 张主牌、15 张额外的首次获取及一次联栗炮两段成功结算。
- 当前实机适配 Unity `6000.0.61f1`，尚未在另一台物理电脑完成对局验收；游戏或读取模块更新后可能需要适配。
- 部分特殊等级/阶级变化尚未全面实测；程序不模拟全部发动限制、连锁与无效等规则，请参照游戏核对并自行操作。
