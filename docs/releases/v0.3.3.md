# MD助手 v0.3.3

Windows x64 单文件便携版。下载 EXE 后双击运行。随附的 SHA-256 文件可用于校验下载。

## 更新内容

- 支持根据「魂之仆从」同次公开结算的日志记录对方已知顶牌，抽入手牌后转入公开手牌记录。
- 中途启动时按公开日志重建盖放记录，后续公开身份可修正原离手记录。已公开身份优先于候选推断，手牌数量不一致时保留不确定性。
- 启动时跳过卡库缓存中格式损坏的条目，保留有效资料并触发刷新。修复系统时钟回拨后的刷新判断，并跳过冷却期内的缺卡扫描。
- 修复源码版的 `启动助手.cmd`。工作区移动或改名后，启动器可从现有 pnpm 安装目录找到 Electron；双击启动不依赖系统安装的 Node.js。
