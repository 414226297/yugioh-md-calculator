# MD助手 v0.3.2

本次更新加入新卡资料自动更新、公开手牌离场追踪修复和对方已知顶牌浮窗。

- 卡片资料每天自动检查，遇到缺失资料时提前更新。自动请求至少间隔1小时，失败保留缓存并重试，支持手动更新。收录进度取决于资料源。
- 已公开的融合素材逐张移除，普通魔陷盖放结合完整公开证据缩小候选，怪兽盖放后公开破坏会修正原离手记录，避免重复扣除。
- 支持绮悠公开结算的顶牌记录、倾斜卡图浮窗，以及已知顶牌抽入手牌后的转移和迟到抽牌日志去重。
- 精简旧交接入口和工作区历史打包副本。

下载 Windows x64 单文件 EXE，可独立复制运行。SHA-256 文件用于核对下载内容。

验证结果为209项自动测试通过、1项跳过。卡库设置与单文件启动使用隔离界面验证。旧整套UI测试仍在等待 #total 时超时，完整实机对局验收待后续进行。部分新卡图片和效果详情仍取决于资料源字段。

默认使用自有只读后端。首次启动需联网获取卡片资料。
