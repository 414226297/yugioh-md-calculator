# 联栗炮助手 v0.1.2

Windows x64 牌组自动识别更新。

- 进入支持的排位或活动准备页面时识别所选牌组，切换已知牌组同步更新。
- 每场返回准备页面后重新核对牌组，连续对局无需再打开编辑页面或手动确认。
- 完整卡表优先从游戏读取，缺失时使用身份及修改时间匹配的助手或本机 Untapped 记录。过期或不完整记录会显示待获取，并阻止沿用旧牌组。
- 保留原有并排侧栏、联栗炮计算和手动核对功能。

排位两副牌组切换、决斗者杯首次加载后返回准备页面、连续两局自动获取已完成实机验收；对局内状态由游戏只读快照加用户确认核对。构建、63项单元测试、12组界面检查、启动检查及便携包验收通过。

首次没有完整卡表或修改后缺少新卡表时，仍需加载一次编辑页面。自动读取依赖兼容的本机原生模块；租借牌组及其他活动尚未全面实测。无手机、主机适配。
