# 自有读取后端（Windows x64）

本目录是项目原创的 Windows 只读内存传输源码，采用项目 MIT 许可。不加载、不复制 untapped-scry，不附带游戏程序、元数据或私人内存快照。

## 当前能力

- MemoryHost 仅以 PROCESS_VM_READ / PROCESS_QUERY_INFORMATION 打开 masterduel，支持有边界的单次和批量读取、模块枚举，无写入或注入。
- 原创 IL2CPP v31/v39 解析与对象访问；支持v39变长类型索引，按 GameAssembly SHA256 匹配已实测版本，不匹配时明确报错，不猜测地址或回退第三方。
- 实测通过主菜单、牌组编辑、准备页牌组身份、对局数量及公开日志、公开手牌与离手扣减。未知卡片身份不会被补读。
- 公开日志的手牌展示action31可恢复短暂展示中漏采的卡名；draw/name/reveal严格相邻时关联同一次抽卡，避免重复计数。已用真实热血指导王三次公开日志离线验证，后续发动的卡片正常离手。
- 新安装默认使用自有只读后端；设置中仍可切换兼容后端。不要求 .node 路径，不访问 Untapped 牌组缓存。明确保存过的旧后端选择会保留。
- 构建自动生成 dist/reader/owned/MD.MemoryHost.exe，便携包白名单包含该原创程序，不包含第三方模块。
- 快照最终一致性复核采用最多 128 段、合计 1 MiB 的批量请求；离线自检已通过，优化后实机耗时尚未重新测量。

## 构建和测试

Windows 构建需要系统 64 位 .NET Framework 4.x 编译器，无需 dotnet SDK。运行需要 Windows .NET Framework 4.x。

```powershell
pnpm run build
pnpm test
node scripts/test-owned-reader.mjs
pnpm run test:ui
```

普通测试不要求安装 Untapped。仅显式设置 MD_TEST_COMPANION=1 时运行第三方模块集成测试，可用 MD_SCRY_PATH 指定本机路径。界面测试使用离线测试模式，不连接游戏。

格式参考：Windows ReadProcessMemory API，以及 Cpp2IL 的 IL2CPP v31 元数据结构定义；未引入其实现或二进制。
